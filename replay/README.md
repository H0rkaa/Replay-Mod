# 🎮 Minetest Replay Mod

A Minetest mod that lets you **record**, **replay**, and **undo** changes made to the world.  
Inspired by the Minecraft Replay Mod, this tool is designed for creating demos, videos, or testing features in a controlled environment.

---

## 🛠️ Key Features

- Record world modifications in real time.
- Replay saved sessions in a dedicated replay world.
- Undo specific replays to return the world to a previous state.
- Isolated replay environments to preserve the original world.

## 📦 Installation

1. Clone or download this repository into your Minetest `mods/` folder.
2. Enable the mod in your world settings.
3. Use the in-game commands to manage recordings and replays.

---

## 💡 Usage

In-game commands:

- Start recording: `/r_start <name>`
- Stop recording: `/r_stop`
- Play a replay: `/r_play <name>`
- Undo a replay: `/r_undo <name>`

All replays are played in a separate replay world to avoid altering your original world.
